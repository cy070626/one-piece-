COMBAT STUDY

先读距离，再接连招。

十名草帽伙伴各有自己的打法。拳脚、剑术、弹弓、施法、机械与空手道各有起手，先熟悉自己的安全距离。

01 / CONFIRM

命中确认与接招

J 打中或被防住后，等有效期结束，在收招阶段按 K，可取消剩余收招。只能向更高阶技能接招；挥空后需要完整收招。对手仍能利用距离、防御或资源不足反制。

02 / SPACE

攻击会留下破绽

技能说明书可以切换近、中、远距靶。大招前段小幅击退，末段击退与击飞。超出判定范围会落空；弹幕有飞行距离，区域技会提前标记落点。

03 / RESOURCE

争夺翻盘机会

蓝条通过时间、进攻、受伤与防御补充。饮料和烤肉可缓解落后，道具最多以75%的概率向弱势方附近倾斜；双方仍可抢夺。暂停每回合累计30秒。

建议顺序：二连跳与走位 → 防御反击 → 命中接招 → 资源与极限释放。

距离回能、后撤与起手护持

双方相距至少260像素，连续1.5秒不出招、不受击且不防御，场上也无本方弹幕、召唤物或持续地形，自动回能由2.1提高至3.6/秒；重新出招、受击、防御或靠近即重新计时。劣势加成与虚弱仍影响该速度，能量上限100。

E战术后撤：落地且无硬直时使用，12能量、3秒冷却，无无敌或霸体。速度随角色移速变化，起手0.05秒、移动0.13秒、收招0.20秒；不能取消正在进行的攻击，墙边步程会缩短。H武装生效时，物理K/L额外消耗6能量，起手最初0.10秒霸体并减伤15%，之后可打断。

特殊能力的条件与反制

饼干士兵最多2名，能被击毁，不阻挡角色移动；攻击克利架本体使助手短暂停顿。本体倒下或果实封锁时助手消散。艾恩缩小对手3至4秒，攻击降低12至15%、移速降低10%；不改变生命、受击框和跳跃，结束后4秒同类抗性。

布鲁诺L逐扇放门，每扇14能量、10秒；两门间距150至640像素才连通。本方靠近入口按F自选，对手落地进入42像素入口且无受击硬直时自动传送，当前出招取消。入口0.15秒预警可打断，出口0.25秒收招无无敌；本方1.2秒间隔，对手2秒内不再次触发。R/T远程收回门1/2，1秒共享回收冷却。汉库克的石化最多0.65秒，被后续有效伤害打破，结束后3秒抗性。莫利亚L建立可被击毁的影分身，再按L额外12蓝换位一次；长冷却仍保留。

这些技能沿用前摇打断、同帧互换伤害、防御、连段递减、资源倾斜及30秒暂停。每招具体参数与演出见角色技能卡。

果实与霸气如何对抗

自然系的 L 特殊技在有效期开始元素化，持续0.8至1.2秒，普通物理伤害降低90%，抵抗物理击退和打断，每秒另耗6能量，再次出招解除。能力攻击、场地伤害与霸气攻击可以反制；暗暗果实不享受通用元素化免伤。

动物形态、橡胶巨拳与武器缠绕附在角色技能上；形态视觉扩大不会扩大受击框，也不会新增通用无敌。形态强化、霸王强化及具体数值均为本作同人玩法。进入技能说明书查看逐招条件与反制。

01 / NAVIGATION

从选角到开战

方向键选择角色，Tab 在按钮间移动，Enter 确认。选角下方的确认栏始终可见。搜索名称或风格，按阵营筛选，展开单招查看数值和反制。设置页选择对手、CPU难度、模式与场地，Enter 开战；Esc 返回选角。

战斗中 P 或 Esc 暂停及继续，每回合累计最多30秒。返回网站会结束当前对局。结果页按 Enter 进入下一局。

02 / MOVEMENT

二连跳与场地路线

A / D 左右移动，W / 空格 跳跃。松开后在空中再按一次，可二连跳，落地恢复次数；长按不会无限跳。受击硬直及出招期间无法起跳。所有角色使用一致的受击框高度，巨大外观不封死跳跃路线。

晴日港口为平地。暮色中央斜坡有55像素高差。月下为左右470高度平台及中央370高度平台；向上穿过，下降可落在平台上，走出边缘落下。道具也会落在对应平台上。地形无额外伤害，双方均可使用。

03 / ATTACK

前摇、有效期、收招

J 轻击，K 重击，L 特殊，I 必杀。每一招都有准备、判定和收招阶段。冷却从出招开始计时。下方技能栏显示就绪、能量缺口和剩余冷却秒数，动作中会显示等待接招。

普通命中可打断攻击的各个阶段；已发射的弹幕继续飞行。区域技锁定落点并显示预警，不会自动追踪逃开的对手。输入有8帧缓冲。

04 / COMBO

命中确认与连段

打中或被防住后，在收招阶段可接更高阶招式，例如 J → K → L → I。挥空不能取消，低阶不能打断高阶。每段伤害只结算一次；前段小退，末段强退，大招末段短暂击飞。连续伤害按连段递减，最低为基础的50%。

05 / SAME FRAME

同时出招怎么判

同帧有效攻击互相命中，双方伤害、硬直和击退同时结算，必杀与S级没有通用优先权。快招先命中可打断慢招的前摇；防御、霸体和无敌以命中帧状态为准。双倒判平局重赛。

伤害先于换位生效，同帧受击可打断位移。双方空间技能同帧生效时位移互相取消，消耗与冷却保留；已发射的弹幕在施法者受击后继续飞行。

06 / DEFENSE

防御、霸体与无敌

S 面向对手防御，减伤88%，按攻击强度消耗护盾；耗尽破防，硬直42帧。停止防御才恢复护盾。跳过弹幕、越过对手或离开预警也是防守。

霸体仅在防守技有效期抵抗普通打断，仍受伤与小退。无敌仅在规避技有效期生效，前摇及收招可被打断。两种状态有醒目文字提示，大招没有通用免伤。

07 / FRUIT

果实能力与控制

冰冻、丝线、暗水等招式可造成短时30%减速，持续秒数写在每招说明中。暗水命中后有限牵引，防御、霸体、无敌可抵抗牵引，范围外无法吸住。震击与部分重击可以击飞，普通硬直、击退和击飞也有具体参数。

ROOM换位消耗35能量、10秒冷却，需双方落地、230像素内、高度差不超过60像素，防御、霸体、无敌抵抗换位。黄猿闪身踢为220像素内有前摇的位移，消耗38、7秒冷却，防御可抵抗。乔巴医疗强化恢复40生命，消耗30能量、10秒冷却，前摇可打断。
岩浆区和冰面持续2秒、半径75像素；岩浆最多3次基础12伤害，防御和无敌有效且不打断；冰面减速30%，离开后0.5秒恢复。跳跃或离开均可避开。青雉冰河时代末段冻结0.60秒，未被防御或霸体抵抗的命中减速2秒；后续非地形有效伤害破冰，结束后4秒冻结抗性。黄猿勾玉首个有效帧获得3秒闪光加速，移速+18%，J/K前摇和收招缩短约12%，不缩短冷却；受击仍可打断，果实封锁清除加速。赤犬用残留岩浆持续限制落点。演出光芒不自动增加伤害。四分五裂、沙化、光化均需付出能量和冷却，没有永久免疫。

08 / RESOURCE

蓝条、道具与翻盘

初始20能量，上限100，每秒恢复2.1。生命比例落后至少18个百分点时，自动回能增加25%。命中、受伤和成功防御补充能量；普通必杀按角色消耗60至85能量。三大将均消耗75，中心射程400像素、命中区宽320像素。赤犬前摇0.82秒、收招1.20秒、8秒冷却；青雉前摇0.80秒、收招1.25秒、9秒冷却；黄猿前摇0.53秒、收招0.90秒、9秒冷却。预警之后不追踪，可二连跳离开或防御反击。

首件道具在6秒预警，之后每8秒一件，最多同时保留2件。生命差和角色均衡评分影响落点，倾向弱势方的概率上限75%，倾斜时70%选择恢复类。双方仍可争夺。烤肉恢复180生命，饮料+25能量。力量攻击+20%、守护减伤20%、疾风移速+15%，持续5秒，相同效果刷新时长。

09 / LIMIT

强化的收益与代价

Shift + I 极限释放，需满100能量、必杀就绪，每回合一次。消耗全部100，释放强化必杀并强化5秒，攻击+15%；随后虚弱3秒，攻击和移速−15%，自动回能减半。被打断不退款，强化计时继续。

S级白胡子、大妈、凯多、鹰眼、赤犬、黄猿、青雉以较高爆发配合较长前摇和收招；极限攻击+20%，结束后虚弱5秒，攻击与移速−20%。S级表示高风险能力上限定位，六维图中的胜率与均衡评分为独立机器人基准。所有大招仍可防御、打断和躲避，等待虚弱期可反攻。

10 / MODES

回合、练习与成长

标准三局两胜，每回合60秒，生命耗尽提前结束；超时比较剩余生命比例，平局重赛。练习模式无限时，低于15%生命自动恢复，适合尝试技能和不同距离。生存挑战继承剩余生命，能量重置，挑战下一名对手。

先用入门CPU练习防御，再提高难度。观察前摇，命中后接招，挥空后退出距离，留出能量应对下一次交锋。角色卡介绍优势、弱点与控制时间，可针对对手改变路线。

11 / WATCH

CPU演示与回放

CPU双边演示沿用实际对决规则与难度，支持0.5、1、2倍观看速度，P/Esc暂停。完成一局后可立即回放；浏览器仅保存同一版本的最近一局。

回放支持拖动进度与逐帧，按记录的输入和道具种子重放，终局显示一致性校验。暂停时点击“查看下一帧”；暂停额度仍为每回合累计30秒。回放期间无法改变攻击输入。

12 / TEAM

三人团队赛

每方选3名不同角色，按顺序每组派出1人。生命、能量、道具和极限机会每局重置，每组先赢2小局得1大分，团队先赢2组的队伍获胜；平局由同一组角色重赛。

可以填写海贼团名称、船号和80字内的背景。背景仅用于展示。开局可选玩家对电脑、电脑对电脑或本机双人，控制方式在禁选前确定。

13 / BAN

禁用与编队

双方各禁用对方3名角色，禁用阶段完成后再进入三人编队。每队保留35名可选角色，两队可选择同一个角色，同队内禁止重复。

禁用名单必须互不重复，被禁用角色在对应编队中置灰，无法选择。禁用能限制某些对阵，但不保证真人胜率相同。了解对手射程和反制条件后再安排出战顺序。

人物基础能力参考官网；招式组合、地形、强化条件、评级与数值均为同人游戏设计。普通介绍避免重大剧透。

练习与战场道具

长前摇招式应在拉开距离、命中击飞后或对手长收招时准备。白胡子L在180像素外切换破空震波，I仍需接近170像素；后撤可以支持牵制与资源操作，不能保证近距必杀命中。不同角色的衔接路线见角色卡。

入门：较慢反应与较少防御，适合熟悉出招。进阶：管理距离、霸气与常规反制。专业：较快反应，识别可见投射物、处罚收招、争夺良性道具并使用后撤。三档共享同一角色数值，不增加CPU生命、伤害或能量；隐藏的对手不被自动追踪。

E战术后撤：12能量，3秒冷却，后撤速度按角色移速计算（8.5至14像素/帧），仅落地且没有出招、蓄力或受击硬直时可用；前摇0.05秒，后撤0.13秒，收招0.20秒，无无敌、无霸体，边界限制移动。先防住攻击，再松开S按E，获得蓄力与远程起手的空间。P2小键盘7后撤。

赛后CPU战术复盘按实际战斗记录显示关键时刻、挥空、资源和反制建议。角色卡直接展示SS/S/A/B参考评级，以A档为主，并注明玩法路线与优劣势。

毒性、隐身与战场道具

麦哲伦的命中可附加单层中毒，12至18生命/秒，持续2至3秒；新命中刷新，不叠层，防御或霸体抵抗附毒。烤肉和解毒剂可解除。希留L透明化：28能量、12秒冷却、持续2.5秒，每秒额外6能量；无法互相攻击，可穿过对方，出招先现身并有0.2秒破绽。

烟雾弹：3秒隐藏对手位置，仍可能互相命中，CPU停止跟踪隐藏对手。减速陷阱：拾取者移动−30%持续2秒；伤害陷阱：70生命，隐身/无敌可避伤。两类危险物均有独立颜色、名称和落点预警。解毒剂解除中毒及减速并补15能量。劣势侧定向投放只使用治疗、能量或解毒剂，危险物不定向惩罚劣势方。玩家对玩家当前同屏显示，隐身轮廓以P1视角呈现，双人信息隐藏待完善。

NAUTICAL NOTES

先认识航路，再扬帆出海。

四片海域与伟大航路、红土大陆共同构成故事的地理背景。伟大航路的岛屿、气候与磁场各具特点，航海士使用记录指针判断航向。

01 / ERA

大海贼时代

罗杰关于宝藏的宣言让无数人走向大海。路飞以海贼王为目标，与伙伴共同寻找 ONE PIECE。冒险的意义也来自每个人独立的梦想。

02 / NAVIGATION

航海需要伙伴

航海士观察天气与航向，船匠维护船只，厨师与船医照顾补给和健康。草帽一伙的十名成员各有专长，协作让漫长航程成为可能。

03 / FACTIONS

海上的不同立场

海贼团追寻不同目标，海军执行海上的秩序，世界政府连接诸多加盟国。人物间的立场和信念各有差异，基础档案保留这些背景。

04 / FRUIT

恶魔果实

自然系可将身体变为对应自然元素；动物系具有动物与人兽变化；超人系涵盖多样的特殊能力。能力者惧怕海水。本游戏仅将选定能力转化为有限招式与状态。

05 / DREAMS

十人的航海目标

绘制世界地图、找到All Blue、成为勇敢的海上战士、探索历史、制造梦想之船，都是伙伴出航的理由。人物档案可以继续查看每个人的基础能力与风格。

06 / YOUR CREW

为自己的船扬帆

团队赛中可以填写海贼团名称、船号与简短背景，安排三人的出战顺序。禁用与编队决定赛前策略；船名和背景只用于展示，不添加隐藏数值。
